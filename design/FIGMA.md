# ไฟล์ออกแบบ (Figma)

ลิงก์: https://www.figma.com/design/ykMCAPkxdlLbhNxbFv21Kg

- หน้า **📱 Screens**: 14 หน้าจอ + Prototype (กด ▶ Present เพื่อลองกดตามลำดับการใช้งาน)
  - แถวบน: หน้าหลัก → เลือกอารมณ์ → เขียนบันทึก → ดู/แก้ไข/ลบ → ยืนยันลบ → ยืนยันลบทั้งหมด
  - แถวกลาง: ตั้งค่า, Night + English, Toast กด Back, ยืนยันออกจากหน้าเขียน, แบนเนอร์กู้ร่าง, Empty state
  - แถวล่าง: จอเล็ก 360×740, แท็บเล็ต 768×1024
- หน้า **🧩 Components**: Mood Face (9 แบบ), Button (4 แบบ), Mood Pill, Back Button, Entry Card, Bottom Nav, Hanging Sign
- ตัวแปรสี: `Theme · Day` และ `Theme · Night`

ไฟล์สำรอง: `design/MoodDiary.fig` (ถ้ามี) — export จาก Figma ด้วย File → Save local copy
